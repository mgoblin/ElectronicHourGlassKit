# Electronic Hourglass Kit Lazarus editor

This directory contains the Lazarus/FPC tooling used to build and test the visual editor for the Electronic Hourglass Kit.

The project is split into a few focused sub-projects:

- `ehgk_editor`: the graphical editor application
- `page_components`: reusable visual components for rendering and navigating hourglass pages
- `led_control`: simplified LED control component used by the editor UI
- `pd_format`: grammar and parser resources for the custom page-definition format

The editor is intended to help design animated page data for the hourglass display and eventually export it in a format usable by the firmware examples in this repository.

## Requirements

Install the Lazarus IDE / Free Pascal toolchain and one of the supported widgetsets.

On Debian or Ubuntu:

```bash
sudo apt-get update
sudo apt-get install lazarus fpc
```

For GTK2 builds:

```bash
sudo apt-get install gtk2-engines-pixbuf gnome-themes-extra libgail-common
```

For Qt5 builds:

```bash
sudo apt-get install libqt5pas-dev lcl-qt5
```

## Build the editor

From the project root:

```bash
cd src/utils/ui_editor/lazarus/ehgk_editor/src
lazbuild -B -r --bm=Release ehgk_editor.lpi
```

This produces a release build of the editor app.

## Build reusable component packages

The custom components are packaged as Lazarus packages.

```bash
cd src/utils/ui_editor/lazarus/page_components/src
lazbuild pagecomponents.lpk
```

```bash
cd src/utils/ui_editor/lazarus/led_control/src
lazbuild ledcontrol.lpk
```

## Run the tests

Unit tests are included for the page and LED components.

```bash
cd src/utils/ui_editor/lazarus/page_components/test
lazbuild EhgkPageUnitTests.lpi
./EhgkPageUnitTests
```

```bash
cd src/utils/ui_editor/lazarus/led_control/test
lazbuild LedUnitTests.lpi
./LedUnitTests
```

## Page definition format

The `pd_format/grammar` folder contains a grammar for a custom page-definition format used by the editor and the firmware pipeline. It includes the lexer/parser sources and related helper scripts.

Generate or inspect the grammar with:

```bash
cd src/utils/ui_editor/lazarus/pd_format/grammar
./build.sh
```

The grammar files are:

- `pd.l`
- `pd.y`
- `lineno.l`
- `example.pd`

This format is experimental and may evolve as the editor capabilities expand.

## Typical workflow

1. Open the editor application.
2. Create or edit LED pages for the hourglass.
3. Arrange the animation sequence and timing.
4. Export page data in a format that can be consumed by the firmware examples.
5. Use the generated page definitions in the embedded project or convert them into a C/HEX-ready representation.

## Notes

- The project is a companion to the firmware examples under the repository root and the `src/stages` code.
- Build artifacts such as `lib/x86_64-linux` are generated by Lazarus and are not source files to edit directly.
- For OS-specific UI issues, prefer the GTK2 or Qt5 widgetset support described above.
